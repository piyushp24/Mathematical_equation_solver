# Mathematical_equation_solver
A deep learning-based system that detects, segments, and recognizes handwritten mathematical symbols from images to reconstruct full equations. Combines OpenCV for image processing and a CNN model trained with TensorFlow/Keras for symbol classification.

Key Features:

Image preprocessing and contour-based character segmentation

Automatic padding and squaring for consistent input shape

Symbol classification using a custom-trained CNN

Equation reconstruction from individual symbol predictions

Tech Stack: Python, OpenCV, TensorFlow/Keras, NumPy, Matplotlib
